# Treinamento com projeto real 
Para praticar os conceitos aprendidos em sala, decidi criar um app de gestao de vendas, já que é uma dor no meu atual serviço, decidi aplicar meus conhecimentos, assim posso desenvolver e treinar meus conhecimentos enquanto estudo.

---
## Comandos e explicação

npm init -y
npm install express mysql2 dotenv cors
npm install -D nodemon

    - express → servidor/rotas
    - mysql2 → conexão com o banco      (versão com suporte a Promises)
    - dotenv → variáveis de ambiente (senha do banco etc.)
    - cors → permitir o frontend acessar a API
    - nodemon → reinicia o servidor sozinho a cada alteração (só dev)
